# Library Management System

## About

A console-based Library Management System built in C. The program allows users to manage a collection of books and perform basic library operations such as adding, displaying, searching, issuing, and returning books.

This project focuses on practicing structures, arrays, functions, pointers, strings, loops, and menu-driven program design.

## Features

* Add new books to the library
* Store book ID, title, author, and availability status
* Display all available books
* Search for a book using its ID
* Issue available books
* Return issued books
* Prevent issuing an already issued book
* Handle books that cannot be found
* Interactive menu-driven interface
* Supports up to 100 books during program execution

## Concepts Used

* Structures (`struct`)
* Arrays of structures
* Functions
* Function parameters
* Pointers
* String handling
* `strcmp()` and `strcpy()`
* `fgets()` and `scanf()`
* `for` loops
* `do-while` loops
* `switch` statements
* Conditional statements
* Input/output with `stdio.h`
