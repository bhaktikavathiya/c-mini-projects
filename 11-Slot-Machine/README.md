# Slot Machine

## About

Slot Machine is a command-line game written in C that simulates a simple slot machine. The player can spin three reels containing random symbols and win points based on matching combinations.

## Note

If emojis do not display correctly in the VS Code terminal on Windows, switch the terminal to UTF-8 by running: chcp 65001

## Features

* Spin three random reels
* Display slot symbols using emojis
* Detect jackpot (three matching symbols)
* Detect small prize (two matching symbols)
* Display a losing message when no symbols match
* Menu-driven interface

## Concepts Used

* Variables
* Arrays
* `printf()`
* `scanf()`
* `switch`
* `for` loops
* `if`, `else if`, `else`
* Random number generation using `rand()`
* Seeding random numbers with `srand()` and `time()`
