# Mood Recommender

## About

Mood Recommender is a command-line application written in C that suggests a simple activity or piece of advice based on the user's current mood. The user selects a mood from a menu, and the program displays a personalized recommendation using a `switch` statement.

## Features

* Select from 10 different moods
* Display a personalized recommendation for each mood
* Handle invalid menu choices
* Friendly command-line interface
* Encouraging closing message

## Concepts Used

* Variables
* `printf()`
* `scanf()`
* `switch` statement
* `case` labels
* `break`
* `default`
* User input
* Conditional program flow
