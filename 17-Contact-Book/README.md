# Contact Book

## About

Contact Book is a command-line application written in C that allows users to store and view contact information. The program can store multiple contacts, with each contact containing a name and phone number. It uses structures to group related information together and functions to organize the program.

## Features

* Add new contacts
* Store up to 20 contacts
* Store contact names and phone numbers
* View all saved contacts
* Display a message when no contacts are saved
* Menu-driven command-line interface
* Exit the program through the menu
