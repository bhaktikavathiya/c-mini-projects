# To-Do List

## About

To-Do List is a command-line program written in C that allows users to manage their daily tasks. The program lets users add tasks, view all added tasks, and exit the application. It uses structures and arrays to store multiple tasks efficiently during program execution.

## Features

* Add new tasks
* Store multiple tasks using structures
* View all added tasks
* Handle empty task lists
* Prevent adding tasks beyond the storage limit
* Uses a menu-driven interface for user interaction

## Concepts Used

* Structures (`struct`)
* Arrays of structures
* Variables
* `printf()`
* `scanf()`
* `fgets()`
* `switch` statements
* `while` loops
* `for` loops
* Conditional statements (`if`, `else`)
* Array indexing
* Input buffer handling using `getchar()`
* Basic input validation
