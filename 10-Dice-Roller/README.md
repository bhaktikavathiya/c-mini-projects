# Dice Roller

## About

Dice Roller is a command-line program written in C that simulates rolling one or two six-sided dice. The program generates random dice values, displays the result of each roll, and calculates the total when rolling two dice.

## Features

* Roll one die
* Roll two dice
* Display the total of two dice
* Menu-driven interface
* Generate random dice values using the C Standard Library

## Concepts Used

* Variables
* `printf()`
* `scanf()`
* `if`, `else if`, `else`
* Arithmetic operators
* Random number generation using `rand()`
* Seeding random numbers using `srand()` and `time()`
