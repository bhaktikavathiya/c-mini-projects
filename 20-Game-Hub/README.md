# Game Hub - Tournament Mode

## About

A console-based Game Hub built in C. The program allows players to play multiple mini-games and participate in a tournament-style scoring system with a live scoreboard and ranking system.

This project focuses on practicing functions, arrays, pointers, strings, random number generation, loops, conditionals, and menu-driven program design.

## Features

* Play Guess the Number
* Play Rock Paper Scissors against the computer
* Play Hangman with letter validation and repeated-guess detection
* Play a Dice Challenge with one or two dice
* Maintain a cumulative tournament score
* Display points earned after each game
* Display current score and games played
* Calculate average score
* Assign tournament ranks based on score
* Handle invalid game choices and inputs
* Interactive menu-driven interface
