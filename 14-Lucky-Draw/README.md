# Lucky Draw

## About

Lucky Draw is a command-line program written in C that randomly selects a winner from a list of participants entered by the user. Every participant has an equal chance of winning, making it a simple demonstration of random number generation and string handling in C.

## Features

* Enter up to 20 participant names
* Validate the number of participants
* Store participant names using arrays
* Randomly select one winner
* Display the winner instantly
* Simple command-line interface

## Concepts Used

* Variables
* Character arrays (strings)
* Two-dimensional arrays
* Functions
* `printf()`
* `scanf()`
* `for` loops
* `if` statements
* `rand()`
* `srand()`
* `time()`
* `#define` macros
