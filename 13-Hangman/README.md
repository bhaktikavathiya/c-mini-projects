# Hangman

## About

Hangman is a command-line word guessing game written in C. The player has to guess the letters of a hidden word before running out of lives. Correct guesses reveal the letters in the word, while incorrect guesses reduce the remaining lives. The game ends when the player either guesses the entire word or loses all lives.

## Features

* Guess one letter at a time
* Display hidden letters using underscores
* Reveal correctly guessed letters
* Track remaining lives
* Detect Win or Game Over
* Simple command-line interface

## Concepts Used

* Variables
* Character arrays (strings)
* Arrays
* `printf()`
* `scanf()`
* `for` loops
* `while` loops
* `if`, `else if`, `else`
* Character comparison
* String traversal using array indexing
