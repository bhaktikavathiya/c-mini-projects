# Mini Banking System

## About

Mini Banking System is a command-line banking application written in C. It allows a user to check their account balance, deposit money, and withdraw money. The program uses functions and pointers to organize the banking operations and modify the account balance.

## Features

* Check current balance
* Deposit money
* Withdraw money
* Prevent zero or negative transactions
* Prevent withdrawals greater than the available balance
* Menu-driven interface
* Continue performing transactions until the user exits
* Fixed starting balance of ₹10,000

## Concepts Used

* Variables
* Functions
* Function parameters
* Pointers
* `float` data type
* `printf()`
* `scanf()`
* `do-while` loop
* `switch` statement
* `if`, `else if`, `else`
* Conditional logic
* Address operator (`&`)
* Dereference operator (`*`)
* Basic input validation
